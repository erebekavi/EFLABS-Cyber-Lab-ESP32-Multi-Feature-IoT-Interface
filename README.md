# EFLABS-Cyber-Lab-ESP32-Multi-Feature-IoT-Interface
EFLABS Cyber Lab is an ESP32 DevKit V1-based IoT project featuring an OLED UI, physical buttons, WiFi scanning, 2.4GHz channel analysis, BLE device scanning, WiFi information, real-time RSSI monitoring, device diagnostics, and optional NeoPixel control. Built for embedded systems, IoT, and wireless networking.
